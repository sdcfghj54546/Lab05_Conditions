## Ответы на вопросы

**1. Чем `int.TryParse()` безопаснее `int.Parse()`? В каких случаях стоит использовать каждый?**
`int.Parse()` выдает исключение (ошибку) и «роняет» программу, если строка не может быть преобразована в число. `int.TryParse()` просто возвращает `false` и не ломает программу. `TryParse` лучше использовать при вводе данных от пользователя, так как пользователь может случайно ввести букву вместо цифры. `Parse` можно использовать, если вы на 100% уверены в формате данных.

**2. Когда `switch` удобнее, чем цепочка `if/else if`? Приведите пример из реальной жизни.**
`switch` удобнее, когда мы сравниваем одну переменную с конкретными значениями (числами, строками). Это делает код визуально чище. Пример из жизни: выбор блюда в ресторане по номеру (1 — суп, 2 — салат, 3 — стейк). В коде лабораторной это меню с выбором действия и определение сезона по номеру месяца.

**3. Что произойдёт в `switch`, если убрать `break` после одного из `case`?**
Произойдет «проваливание» (fall-through). Программа выполнит код этого `case`, а затем сразу перейдет к выполнению кода следующего `case` (даже если его условие не совпало), и так до тех пор, пока не встретит `break` или конец блока `switch`.

**4. Чем отличается `=` от `==` в C#? Почему это частая ошибка?**
Один знак `=` — это оператор присваивания (записать значение в переменную). Два знака `==` — это оператор сравнения (проверить, равны ли значения). Это частая ошибка, потому что в математике мы привыкли использовать один знак равенства для сравнения, а в программировании для этого нужен другой оператор.

**5. Можно ли написать тернарный оператор внутри другого тернарного оператора? Приведите пример из кода лабораторной и оцените читаемость такого кода.**
Да, можно. Например, в игре «Угадай число» можно было бы написать так: `string result = attempts <= 7 ? "Отлично" : attempts <= 15 ? "Хорошо" : "Можно лучше";`. Однако вложенные тернарные операторы сильно ухудшают читаемость кода. Лучше использовать их только для простых условий «одно из двух», а для сложных ветвлений — `if/else`.
